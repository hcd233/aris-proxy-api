Architecture · aris-proxy-api · LLM Proxy Gateway

aris-proxy-api 架构全景

一个 Go 实现的 LLM 代理网关与管理后台：统一接入多个 MaaS 平台与 API 协议，承载 7 条跨协议转发路径，向下沉淀会话与审计数据，向上提供管理 API、训练数据导出与 Agent Harness Trace 分析。以下十四张图分别刻画 DDD 分层总览、LLM 代理链路、上游容错（熔断/隔离/降级）、会话数据模型、Trace 摄取管线、Web 管理后台前端架构、前端内嵌交付链路、部署发布拓扑、运维运行时治理、运行时指标、优雅退出、敏感词热更新、定时任务与 Demo 演示账户架构。

运维与运行时治理

09

运行时指标采集与聚合

进程内采集器（HTTPCollector / SSEGauge / TokenUsageCounter / Go runtime）注册进 Prometheus Registry；每 Pod 一个 Metrics Flusher 周期 BuildSnapshot 写入 Redis 快照（ZSET + 实例注册表，retention 24h 清理）；运行时大盘经聚合层对相邻快照做 delta/桶宽 计算 QPS / P95 / 成功率 / CPU% / tokens·s；Prometheus /metrics 直读本 Pod Registry。

10

优雅退出序列

SIGINT / SIGTERM 触发 Fx Lifecycle OnStop 逆序执行（注册顺序为 Redis → DB → BlockedService → Logger → HTTP → Flusher → Inflight → Pool → Cron，故 OnStop 反序）。依次停 cron（3min）→ 停 pond 协程池（3min）→ inflight drain 等在途（5min）→ 关 HTTP（ShutdownWithContext 30s，泄流 SSE 长连接，停 Flusher）→ 同步日志 → 关 DB → 关 Redis。K8s 配合 preStop sleep 10 + terminationGracePeriodSeconds 660 无损下线。

11

敏感词热更新

管理后台 /block 写入 DB 后 NotifyChanged 经 Redis Publish(blocked:changed) 即时信号 + INCR(blocked:version) 版本广播；各 Pod BlockedService 通过 pub/sub 订阅、版本轮询（2s）与低频兜底（5min）三重同步触发全量 Rebuild 内存 Aho-Corasick matcher；LLM 请求经 Check 命中后按 action 拦截（deny）或打码（omit），命中计数经 BlockedHitSync cron 每 5min 批量回写 DB。

12

定时任务触发与执行

管理后台 /cron 更新 spec/enabled 或手动触发；CronManager 热重载（Restart/Enable/Disable）并经 cron:reload Redis pub/sub 跨 Pod 广播（其他 Pod handleMessage 同步）；任务以 Redis 分布式锁（TTL 5min + ticker 续期）保证单实例执行，wrapCronFunc 注入 traceID、panic 恢复与 enabled 检查，每次执行落 CronCallAudit（status + duration + trigger source）。

13

Demo 演示账户架构

四级权限 pending(1) < demo(2) < user(3) < admin(4)：登录页「Continue as Demo」经无鉴权 IP 限流端点（5s/8）一键登录，DemoLogin 命令校验 login_enabled 并定位 demo 单例用户签发 JWT；前端 isDemo() + demoModules 驱动 PermissionGuard 三态守卫与 Nav/删除按钮锁定；admin 经 users 页与 PATCH /api/v1/demo/config 治理；运行时权限中间件按模块白名单放行（fail-closed），行为数据 WHERE id % K = 0 抽样，写接口与存量 API Key 因 demo < user 天然拒绝。

14

上游容错 · 熔断 / 隔离 / 降级

Guard 在重试外层：熔断 Allow → 信号量 Acquire → 放行转发 → Report 回写 · 拒绝降级 503 + Retry-After · Prometheus 指标按 endpoint key 暴露

分层契约与关键决策

  • 依赖注入 go.uber.org/fx，模块分组 bootstrap/modules/：Infra / Cron / Repository / Application / Handler。
  • 分层契约：handler 只依赖 application/*/port；application 只依赖 domain 接口；domain 只依赖 repository 接口。
  • 全局中间件链：Recover → Metrics → Inflight → Guard → Fgprof → CORS → Compress → Trace → Locale → Log。
  • 优雅关闭：停 cron → 停协程池 → draining → 等在途 → 关 HTTP → 同步日志 → 关 DB → 关 Redis。
  • 异步协程池 pond：SubmitMessageStoreTask / SubmitModelCallAuditTask，不阻塞响应链路。

7 条跨协议转发路径

  • OpenAI Chat native · Chat → Anthropic · Response native · Response → Chat · Response → Anthropic · Anthropic Message native · Message → Chat。
  • 3 个 converter：AnthropicProtocolConverter / OpenAIProtocolConverter / ResponseProtocolConverter。
  • 收尾 seam recordModelCall：审计 + Token 扣减（Lua）+ 指标 + 状态归一化；会话落库由相邻 MessageStoreTask 完成。
  • 上游重试：连接错误 / 5xx / 429 可重试（指数退避 + jitter），4xx 不可重试。

关键默认参数（代码实测）

  • 限流：请求 100/min + Token 2M/min（per API Key，Redis 令牌桶）。
  • Trace spool：256MiB 上限 · 批量 500 条 / 4MiB · 超时 5s · rejected 保留 7d。
  • K8s：limits 512Mi/300m · GOMEMLIMIT 440Mi · preStop 10s · grace 660s。
  • Cron：dedup 每小时 · purge 周日 04:00 · think 每日 00:00 · hit-sync 每 5min · 锁 TTL 5min + ticker 续期。
  • 敏感词热更新：Publish 即时信号 + 版本轮询 2s + 低频兜底 5min，各 Pod 全量 Rebuild AC matcher。
  • Metrics：每 Pod Flusher 周期采集写 Redis 快照（retention 清理），聚合层 delta/桶宽 求 QPS/P95/成功率/CPU/tokens。
  • 缓存/分享：SessionDetailCache TTL 1h · 分享默认 24h（1d/7d/30d/never）。

前端与交付契约

  • 前端是独立 npm 工程 web/，不参与 go module；output: export + basePath: /web + trailingSlash，禁止引入需要 SSR/Edge 的依赖。
  • 所有 HTTP 调用收敛在 src/lib/api-client.ts：Bearer 注入、401 单飞 refresh、业务错误码 → i18n toast；业务组件禁止直接 fetch。
  • src/lib/types.ts（742 行）镜像后端 huma DTO，后端改字段必须同步；后端侧 DTO 约定由 lint conv 强制。
  • i18n 三语（en/zh/ja）+ CJK 字号缩放 + Category Reserve 宽度预留，切换语言不产生布局跳变；后端文案按 Accept-Language（zh/en）返回。
  • 主题 anthropic / moonshot 与明暗模式正交，THEME_INIT_SCRIPT 在首屏绘制前写入 data-theme，避免闪烁。
  • 交付：make web-build 逐文件 gzip -9（10MB → 3.5MB）→ embed.FS 随二进制发布；CI 的 path filter 不含 web/**，纯前端改动不会触发镜像重建。
