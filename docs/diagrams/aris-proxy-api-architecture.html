aris-proxy-api 架构全景

一个 Go 实现的 LLM 代理网关与管理后台：统一接入多个 MaaS 平台与 API 协议，承载 7 条跨协议转发路径，向下沉淀会话与审计数据，向上提供管理 API、训练数据导出与 Agent Harness Trace 分析。以下七张图分别刻画 DDD 分层总览、LLM 代理链路、会话数据模型、Trace 摄取管线、Web 管理后台前端架构、前端内嵌交付链路与部署发布拓扑。

01

系统总览 · DDD 分层

三类客户端 → 接口层 → 应用层 → 领域层（依赖向内）· 基础设施层反向实现仓储接口 · Cron 与 Fx 装配横切

LLM 代理转发核心链路

APIKey 鉴权 → 双层限流 → 敏感词 → EndpointResolver → 跨协议转换 → Transport → 上游 → recordModelCall 收尾 + Pond 异步落库

会话数据模型与生命周期

两路写入（LLM 转发 / Trace 摄取）→ Session 聚合（checksum 内容寻址去重）→ 缓存 / 导出 / 分享 / 审计 / Cron 治理

分层契约与关键决策

  • 依赖注入 go.uber.org/fx，模块分组 bootstrap/modules/：Infra / Cron / Repository / Application / Handler。
  • 分层契约：handler 只依赖 application/*/port；application 只依赖 domain 接口；domain 只依赖 repository 接口。
  • 全局中间件链：Recover → Metrics → Inflight → Guard → Fgprof → CORS → Compress → Trace → Locale → Log。
  • 优雅关闭：停 cron → 停协程池 → draining → 等在途 → 关 HTTP → 同步日志 → 关 DB → 关 Redis。
  • 异步协程池 pond：SubmitMessageStoreTask / SubmitModelCallAuditTask，不阻塞响应链路。

7 条跨协议转发路径

  • OpenAI Chat native · Chat → Anthropic · Response native · Response → Chat · Response → Anthropic · Anthropic Message native · Message → Chat。
  • 3 个 converter：AnthropicProtocolConverter / OpenAIProtocolConverter / ResponseProtocolConverter。
  • 收尾 seam recordModelCall：审计 + Token 扣减（Lua）+ 指标 + 状态归一化；会话落库由相邻 MessageStoreTask 完成。
  • 上游重试：连接错误 / 5xx / 429 可重试（指数退避 + jitter），4xx 不可重试。

关键默认参数（代码实测）

  • 限流：请求 100/min + Token 2M/min（per API Key，Redis 令牌桶）。
  • Trace spool：256MiB 上限 · 批量 500 条 / 4MiB · 超时 5s · rejected 保留 7d。
  • K8s：limits 512Mi/300m · GOMEMLIMIT 440Mi · preStop 10s · grace 660s。
  • Cron：dedup 每小时 · purge 周日 04:00 · think 每日 00:00 · hit-sync 每 5min。
  • 缓存/分享：SessionDetailCache TTL 1h · 分享默认 24h（1d/7d/30d/never）。

前端与交付契约

  • 前端是独立 npm 工程 web/，不参与 go module；output: export + basePath: /web + trailingSlash，禁止引入需要 SSR/Edge 的依赖。
  • 所有 HTTP 调用收敛在 src/lib/api-client.ts：Bearer 注入、401 单飞 refresh、业务错误码 → i18n toast；业务组件禁止直接 fetch。
  • src/lib/types.ts（742 行）镜像后端 huma DTO，后端改字段必须同步；后端侧 DTO 约定由 lint conv 强制。
  • i18n 三语（en/zh/ja）+ CJK 字号缩放 + Category Reserve 宽度预留，切换语言不产生布局跳变；后端文案按 Accept-Language（zh/en）返回。
  • 主题 anthropic / moonshot 与明暗模式正交，THEME_INIT_SCRIPT 在首屏绘制前写入 data-theme，避免闪烁。
  • 交付：make web-build 逐文件 gzip -9（10MB → 3.5MB）→ embed.FS 随二进制发布；CI 的 path filter 不含 web/**，纯前端改动不会触发镜像重建。
