接入步骤

四步，从零到可追溯

不用改客户端代码。每一步不是在控制台点几下，就是敲一条命令。

  1. 01

    登录，拿到 API Key

    用 GitHub 或 Google 登录控制台，管理员审核通过后，在 API Keys 页生成一把专属密钥。

    GitHub / Google 登录管理员审核随时吊销
  2. 02

    接入上游，定义模型别名

    填入各家的 Base URL 和密钥，或用 OAuth 授权 Codex / Claude Code 订阅；再给模型起个别名，绑定一组上游并设置优先级和权重。

    API Key 端点订阅 OAuth优先级 + 权重按模型计价
  3. 03

    装上 aris，一键配好客户端

    一行命令安装 aris 客户端，向导里填服务地址和密钥；再用 aris model export 把可用模型写进你选的客户端，原配置自动备份。

    Claude CodeCodexOpenCodePiDeepSeek Harness
  4. 04

    照常使用，数据自动沉淀

    在客户端里正常写代码、聊天。每次调用都被审计，每段对话都存成会话，可以打分、分享，攒够了一键导出训练集。
